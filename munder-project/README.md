# Funny Kite — Munder Difflin project

Add **this folder** in Munder Difflin: **Add project → pick an existing folder → `munder-project/`**.

It is a handbook for Michael (GOD) and any hired agent. It is not a second Fanvue app. The live automation stays in the parent repo (`fanvue-automation/`, desk on port 3456).
